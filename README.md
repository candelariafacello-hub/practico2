# Práctico 2 - Python + GitHub

## Descripción

Este proyecto fue realizado en Google Colab y tiene como objetivo:

- Estructurar un proyecto Python.
- Crear funciones usando for e if.
- Importar funciones desde otros archivos.
- Utilizar Git y GitHub desde Colab.

La función principal del proyecto permite filtrar números pares de una lista.

## Cómo ejecutar

```bash
python main.py
```
